# Эталонный урок M01L01 — изолированный prototype

Эта папка показывает, как методологический материал Knowledge OS превращается в последовательное мобильное обучение. Production-разделы приложения не изменены.

## Что реализовано

- 17 экранов по маршруту: ситуация → модель → пример → практика → проверка → результат;
- сегментированный прогресс;
- микро-проверка с объяснением ответа;
- микро-практика с сохранением в `localStorage`;
- отдельное завершение урока и бизнес-решение;
- mobile-first компоновка без внешних библиотек;
- демонстрационное заполнение через `?demo=1&screen=13`.

## Как запустить

Откройте папку через любой статический HTTP-сервер и перейдите на `index.html`. Например:

```bash
python -m http.server 8080
```
